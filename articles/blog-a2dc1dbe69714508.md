Google が Gemini 4 Argon を公開しました。プロジェクトを読み、ログを調べ、コードを直し、テストまで任せるなら候補に入れる価値があります。短い文章の修正やメールの翻訳なら、急いで乗り換える必要はありません。

Google が狙うのは複雑なソフトウェア開発、専門的な知識業務、多段階のエージェント作業です。難しい仕事を任せた後、遠回りと人間の後始末がどれだけ減るかを見たいところです。

## 入口によって利用条件が違う

10月13日にグローバル公開が発表されました。有料 Gemini API のモデル ID は `gemini-4-argon`、公式では Stable です。Gemini App と検索の AI Mode は Google AI Pro と Ultra が対象。個人の Antigravity デスクトップと CLI は Ultra が必要で、企業には対象契約や API の入口があります。

**Pro を買っても、すべての開発ツールで Argon が使えるわけではなく、API も無料になりません。** 契約前に入口を確認しましょう。[Google の発表](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/)と[Antigravity の発表](https://antigravity.google/blog/gemini-4-argon-in-google-antigravity)を参照してください。

## 気になるのは厄介な開発作業

見栄えのよいホームページは多くのモデルが作れます。実際のプロジェクトには、時々遅くなる画面、複数言語を壊す共通部品、変更すると回帰が続く古いコードがあります。

Google によると Argon は Chromium の構造変更や Python ADK の最適化に使われました。ADK の事例では長いセッションのメモリ内準備時間を40%削減し、コールドインポートを21%高速化したとしています。既存のシステムを理解し、制約の中で変更する事例は参考になります。

ただ、デモだけで主力を全部入れ替えるのは早い。[モデルカード](https://deepmind.google/models/model-cards/gemini-4-argon/)で Google が公表した数字はこちらです。

| 評価 | Argon | GPT-6 Astra | Claude Opus 5.5 |
|---|---:|---:|---:|
| DeepSWE v1.1 | 77.9% | 74.1% | 74.2% |
| FrontierSWE v2 | 55.0% | 65.5% | 62.3% |
| Terminal-bench 4.0 | 57.4% | 58.2% | 66.4% |

Google の評価で、条件はモデルカードの方法説明から確認できます。コードの課題が変われば順位も変わります。自分のリポジトリで比べるほうが選択には役立ちます。

## 百万トークンの意味を確認する

**1,048,576トークンを入力と出力で共有**します。通常の同期出力上限は65,536。long decode を使うと共有ウィンドウの範囲で長い出力が可能です。百万の入力に加えて百万を出力できる意味ではありません。既存の API 実装でモデル名を変えるだけでも不十分です。

入力はテキスト、画像、動画、音声、PDF。出力はテキストです。画面や動画を解析してコードを書く用途に使えますが、画像や音声生成には別のモデルやツールが必要です。[公式仕様](https://ai.google.dev/gemini-api/docs/models/gemini-4-argon)を参照してください。

長いコンテキストは古いコードの改修や資料の照合に便利です。性能レポート、関連コード、ログを渡し、結論に根拠を付けてもらう。リポジトリ全体を渡して「最適化して」と言うより、仕事を具体化したほうが使える結果になります。

## 優待終了後の費用も計算する

Gemini Developer API Standard、100万トークンあたり米ドル：

| 項目 | 2026年11月30日まで | 12月1日から |
|---|---:|---:|
| 入力 | $2 | $4 |
| 出力、思考を含む | $10 | $20 |
| キャッシュ入力 | $0.10 | $0.20 |

キャッシュは暗黙的方式のみで、入力全体をキャッシュ価格で見積もれません。Argon の無料 API 枠はなく、grounding などのツールは追加料金の可能性があります。[料金表](https://ai.google.dev/gemini-api/docs/pricing)を確認してください。

入力20万、課金対象出力2万トークンなら、キャッシュとツール料金を除いて**優待中は約0.60ドル、終了後は1.20ドル**。半日悩む問題が解決するなら安い。十回同じ推測を繰り返すなら高い買い物です。思考も出力料金に含まれるため、見える答えが短くても請求は小さいとは限りません。エージェントの全呼び出しを合算しましょう。

## 試すなら三つの仕事

**複数ファイルの修正。** 再現手順、テストコマンド、変更禁止範囲を渡し、原因と変更量、テスト結果を見る。

**根拠付きの資料分析。** 契約や仕様を比較し、原文の位置を求める。自信ある文章より追跡できる根拠が重要です。

**ツールを繰り返し使う仕事。** ログ調査、診断、修正、テストで、結果を受けて方針を変えるかを見る。

今の主力と同じ資料、ツール、予算で比較し、成功、時間、総費用、人間の介入回数を記録します。まず medium、難問で high を試すのがよいでしょう。

Google のロボットが7回連続で投げ入れるデモも面白い。動画理解から仮想環境を作り、実機へ移す流れです。ただし特定の内部実演です。開発者には、自分のプロジェクトを直せるかが最初の有用な試験になります。

Argon には、情報が多く、工程が長く、やり直しが高くつく仕事を任せたい。小さな仕事は慣れた安価なモデルで十分です。人間が引き取る回数が減るかを見ましょう。
